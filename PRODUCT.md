# PRODUCT.md — DevSpireHub Project Context

## 1. Product Identity
- **Name**: DevSpireHub
- **URL**: https://devspirehub.com
- **Tagline**: Free Programming, AI, Networking, Ethical Hacking & Projects Platform
- **Core Mission**: Provide simple, step-by-step technical guides, tutorials, and practical projects with real code examples. No accounts, no paywalls, no tracking.

## 2. Audience & User Personas
- **Primary Audience**: Beginners and intermediate software developers, system administrators, security enthusiasts, and engineering students.
- **Reading Context**: Users reading long-form technical tutorials, copying and running verified code snippets, comparing full-stack and systems projects, and utilizing interactive web utilities (e.g. NetPulse, image converter, devtools) on both desktop and mobile devices.

## 3. Brand & Tone Constraints
- **Visual Character**: Practical, technical, credible, and disciplined.
- **Anti-Patterns**: Strictly avoid startup marketing hype ("unleash", "elevate"), neon hacker tropes, crypto/web3 aesthetic clichés, arbitrary purple-to-blue gradients, and generic AI-template "slop" (nested cards inside cards, uniform 3-column repetition).
- **Core Palette**:
  - Primary Base: Deep Navy (`#010D18` foundation, `#08121E` framed surfaces, `#10243A` elevated cards)
  - Primary Brand Accent: Radiant Technical Orange (`#E54415` / `#FF710D`)
  - Semantic Section Accents:
    * Programming: Warm Orange (`#FF710D` / `#FB923C`)
    * Networking & Systems: Tech Blue (`#2179C0` / `#38BDF8`)
    * Ethical Hacking: Bright Red (`#FF0C0C`) / Cyan (`#00D9FF`)
    * Artificial Intelligence: Luminous Pink (`#EC4899` / `#F472B6`)
  - Neutrals: Soft White (`#F8FAFC` headings), Muted Silver (`#CECECE` / `#B7C1CB` body text), Navy-tinted Borders (`#223D57`).

## 4. Technical Constraints
- Zero external CDNs or trackers.
- 100% self-hosted assets and fonts (`Saira`, `JetBrains Mono`).
- Strict WCAG 2.2 AA contrast compliance across all interactive states.
- 100% content integrity: never alter heading hierarchies, URLs, metadata, or article copy.
